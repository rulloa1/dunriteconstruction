How to Use This Log

This document gathers every handwritten note and mark made on the draft Employee Handbook into one clean list, so the team can review and resolve them efficiently. Each item is tied to its handbook section, written out in full, and tagged by the kind of decision it needs. Highlighted text shows the specific wording or placeholder the note refers to.

Please work through each item, write the decision in the Decision / Response box, and return the marked-up copy. Once all items are resolved, the changes will be applied and the handbook given its final formatting pass.

Comment Types

QuestionA decision or clarification is needed from ownership.
Needs InputA placeholder that needs real content (names, numbers, policy).
VerifyConfirm the existing wording is acceptable as written.
EditA suggested change or deletion to the text.
ActionA companion item to create outside the handbook text.
FormatA layout or formatting adjustment.
