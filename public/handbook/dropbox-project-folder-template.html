How to Use This Template

Every project lives in one folder, named the same way, with the same sub-folders inside. This keeps files predictable and makes handoffs, audits, and closeouts painless. Jobs start in the Bid Folder (next page) and move here once contracted.

Naming standard

Name each project folder YYYY — Project Name — Lot/Address (e.g. 2026 — Maple Ridge — Lot 14). Keep file names descriptive and dated where it matters: YYYY-MM-DD Description.

Setting up a new project

  1. Copy the _TEMPLATE — Project folder.
  2. Rename the copy using the naming standard above.
  3. Drop the Project Management Workbook into 01 Contract & Admin.
  4. File documents into the matching sub-folder as the job progresses.
  5. At closeout, confirm every folder is complete and move the project to Archive.

Bid Phase — Before the Contract

Every job starts in the Bid Folder, not the project template. Bid files carry the BID prefix so estimating work never mixes with contracted work.

Bid naming standard

BID_###_ProjectName_Document_MM.DD.YY — bid number, project name, what it is, date received or issued (e.g. BID_123_BlankHouse_PlanSet_06.15.26).

📁 Bids 📁 BID_123_BlankHouse 📄 BID_123_BlankHouse_PlanSet_06.15.26 # plan set as received 📄 BID_123_BlankHouse_Takeoffs_06.16.26 # quantity takeoffs 📁 BID_123_BlankHouse_BidProposal_06.17.26 # bid proposal + budget + schedule 📁 BID_123_BlankHouse_RetBids # returned sub bids 📁 BID_123_BlankHouse_PrevPlans # superseded plan sets 📄 PlanRevis_1_123_BlankHouse_06.14.26 # plan revisions, numbered 📄 PlanRevis_2_123_BlankHouse_06.16.26 📄 PlanRevis_3_123_BlankHouse_06.17.26
Bid proposal folder

The Bid Proposal folder always holds three things: the bid proposal, the budget, and the schedule.

After the contract is signed

  1. Move the whole bid folder into Contracted Projects.
  2. Rename the working files — drop the BID prefix, keep the number and name.
  3. Then set up the full project folder using the standard structure on the next page.
📁 Contracted Projects 📁 123_BlankHouse 📄 123_BlankHouse_PlanSet_06.19.26 # current contract set 📄 123_BlankHouse_BidProposal_06.17.26 # as-accepted proposal 📄 123_BlankHouse_Contract_06.17.26 # executed contract

Standard Folder Structure

📁 YYYY — Project Name — Lot/Address 📁 01 Contract & Admin # contract, insurance, permits, NOC 📁 02 Estimating & Bids # takeoffs, bid packets, leveling 📁 03 Budget & Cost # budget, buyout, change orders 📁 04 Subcontracts & POs # executed subs, purchase orders 📁 05 Plans & Specs # current set, revisions, addenda 📁 06 RFIs & Submittals # RFI log, submittal log, approvals 📁 07 Schedule # baseline & updates, look-aheads 📁 08 Daily Reports & Logs # daily reports, toolbox talks 📁 09 Safety # JHAs, inspections, incidents 📁 10 Photos # by date / phase 📁 11 Invoices & Pay Apps # owner pay apps, vendor invoices 📁 12 Closeout # warranties, as-builts, O&M, lien releases
Tip

Keep only the current plan set at the top of 05 Plans & Specs; move superseded sets into a Superseded sub-folder so no one builds from an old drawing.
